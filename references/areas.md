# Áreas da base de conhecimento

Uma pasta por área. Dentro dela, um manual por assunto.

| Área | Entra aqui | Exemplos de manuais |
|---|---|---|
| Negócios e vendas | modelo de negócio, oferta, preço, vendas, e-commerce, atendimento, negociação | dropshipping, oferta e precificação, vendas consultivas |
| Marketing e conteúdo | tráfego pago e orgânico, redes sociais, copy, marca, funil, e-mail | Instagram, anúncios, copy, TikTok orgânico |
| Programação | linguagens, frameworks, arquitetura, banco de dados, testes, deploy | Node, Next.js, SQL, boas práticas |
| IA e automação | modelos, agentes, prompts, n8n e similares, integrações | agentes, n8n, engenharia de prompt |
| Design | interface, identidade visual, tipografia, edição de vídeo e imagem | UI, identidade visual |
| Finanças | finanças pessoais, investimento, impostos, contabilidade de negócio | impostos de e-commerce, caixa |
| Carreira e produtividade | estudo, hábitos, gestão do tempo, entrevistas, liderança | rotina de estudo, entrevistas |
| Outros | o que não coube; se juntar três notas do mesmo tema, crie a área |

Regras:
- Classifique pelo **uso**, não pelo canal. Um vídeo de programador ensinando a vender software vai para Negócios e vendas.
- Assunto novo dentro de uma área: crie o manual na hora, mesmo com uma técnica só.
- Vídeo com duas áreas: nota na principal, link no manual da outra.
- Não crie área nova para um vídeo só.
